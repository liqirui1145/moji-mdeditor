欢迎使用墨记

一个像 Word 一样顺手，却直接产出 Markdown 的编辑器。文字所见即所得，导出时自动整理为 Markdown。

选中一段文字，试试顶部的 加粗、斜体、下划线、删除线，以及 彩色文字 和 荧光高亮。

好的写作工具，应该让工具本身悄悄退场。

从这里开始

你可以把任何内容放在这里：

  • 项目笔记：用清单理清思路
  • 灵感草稿：专注表达，不被格式打断
  • 技术文档：插入代码块、链接和表格

选中的文字，也可以直接调整对齐方式。

// 也可以插入代码块
const idea = "让写作更自然";
console.log(idea);

准备好了吗？点击右上角的 导出 Markdown，复制你的文字。

颜色、下划线和对齐在 Markdown 中没有原生语法，开启「保留富文本样式」会嵌入 HTML 以完整保留效果；关闭则输出纯净 Markdown。

添加链接

为选中的文字添加可点击的地址。

插入图片

使用网络图片地址，导出后会保留为 Markdown 图片。

支持 http / https 图片地址，请确保图片允许公开访问。

插入表格

生成带表头的 Markdown 表格，后续可以直接编辑文字。

包含 1 行表头；插入后可在表格旁使用快捷操作继续增减行列。

快捷键与使用帮助

少一点鼠标移动，多一点专注书写。

文本样式

加粗Ctrl+B
斜体Ctrl+I
下划线Ctrl+U
添加链接Ctrl+K

段落与文档

标题 1 / 2 / 3Ctrl+Alt+1/2/3
正文Ctrl+Alt+0
无序 / 有序列表Ctrl+Shift+7/8
保存草稿Ctrl+S
导出 MarkdownCtrl+Shift+E
保持 Word 一样的排版体验

选中文字后使用工具栏；在表格内按 Tab 可以跳到下一个单元格。按住 Ctrl / ⌘ 点击链接可在新标签页打开。所有修改都会自动保存在本地。

关于导出

加粗、斜体、标题、列表、引用、代码、表格会转换为标准 Markdown；颜色、下划线和对齐则通过内嵌 HTML 保留。导出面板中可随时切换为纯净 Markdown。
